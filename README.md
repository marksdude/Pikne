# Pikne
A modular and repairable power bank
# Features
- USB PD output up to 45W (may handle 60W)
- 0.91 inch OLED for status monitoring
- Attachable modules
- Repairable design
- Up to 86WH capacity
# Modules:
- LED controller:
  - Up to 2.5A output
  - Home Assistant integration
  - Power monitoring on each output
  - 5V output
  - ESP32-C3 based
- Flashlight:
  - 5700lm max brightness
  - PWM dimmable
# Coming modules
- LiPo charger - Allows you to charge up to 4S LiPos from your power bank
